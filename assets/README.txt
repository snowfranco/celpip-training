Want the background noise to be a REAL recording instead of the built-in
synthesized crowd?

1. Find any royalty-free "call centre" / "office ambience" / "crowd chatter"
   audio file you like (make sure its license allows you to use it on your
   public site).
2. Save it in this folder with exactly this name:

       test-centre-noise.mp3

3. Reload the app. The Busy Lab and Full Chaos levels will now loop your
   recording (at different volumes) instead of the synthesizer.

Delete the file to go back to the built-in sound.
